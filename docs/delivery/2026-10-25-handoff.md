## 本地运行

源码的标准启动、环境变量、数据库迁移与 Linux 部署说明见 [RUNBOOK](../../deploy/RUNBOOK.md)。不需要先运行自动验收脚本。

1. 启动 MySQL 8 和 Redis，设置 `DB_HOST/DB_PORT/DB_NAME/DB_USER/DB_PASSWORD`、`REDIS_HOST/REDIS_PORT`。仅新演示库执行 `scripts/database.py init/migrate/seed`；已有库备份后只 migrate。
2. 使用已构建后端 JAR，或自行构建（跳过测试）：`mvn -B -ntp -f backEnd/pom.xml package -DskipTests`。
3. 开发演示启用 `AUTH_MOCK_LOGIN=true`、`WECHAT_MOCK_LOGIN=true`；运行 `java -Duser.timezone=Asia/Shanghai -jar backEnd/sky-server/target/sky-server-1.0-SNAPSHOT.jar --spring.profiles.active=dev`。默认端口8080。
4. 用户端在 `front/` 执行 `npm ci`、`npm run dev:h5`，默认5173；管理端在 `front-admin/` 执行 `npm ci`、`npm run dev`，默认5177。需要改后端地址时，启动或构建前设置 `VITE_API_BASE_URL`，用户端和管理端保持一致。
5. 虚构种子管理员为 `admin / 123456`，开发验证码默认 `123456`；只用于隔离本地演示。用户可使用两个虚构手机号，分别验证普通购买与拼团操作。
6. 可参考 [答辩演示主线](../thesis/implementation-facts.md#演示脚本) 手工检查商品、地址、购买、支付、取消、团购、配送、核销和报表。状态及金额应以服务器响应为准，失败不应显示成功。

同源或静态托管部署时使用 `front/dist/build/h5` 和 `front-admin/dist`；微信源码使用 `front/dist/build/mp-weixin`。默认 API 为 `http://localhost:8080`，外部设备或远程部署必须按 RUNBOOK 重新指定 API 地址构建，不能把 localhost 当作远程服务器。
