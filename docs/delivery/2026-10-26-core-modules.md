# 核心模块运行与验证交接

本轮按课题说明完成模块收敛，保留绿色小程序、苍穹外卖管理壳以及现有Spring Boot 2.7.3后端。后台仅显示工作台、商品管理、分类管理、订单管理、社区拼团、数据统计六个主菜单。原核销、库存和团购报表链接重定向至对应主模块，套餐和员工页面不再作为业务入口；管理员认证继续保留。

## 功能与运行

- 商品管理统一维护分类、上下架、真实库存、生鲜属性及团购设置，支持本地图片上传；商品销量统一从数据统计读取真实完成订单聚合，移除商品表未维护的冗余销量展示。
- H5和管理端默认使用同源代理；小程序默认访问本机 `http://127.0.0.1:8080`，手机调试需要通过 `VITE_API_BASE_URL` 配置实际可达地址。所有端使用相同后端服务与权限规则。
- 订单页面包含普通配送操作与自提码核销；团购订单增加直接查看拼团进度的入口。地址、历史订单、消费记录、取消和模拟退款保留。
- 本地图片上传校验实际PNG/JPEG内容、大小和尺寸，随机命名，不依赖文件原名或外部云账号。公开只读图片地址支持用户端与后台展示。
- 已启动本机用户端 http://127.0.0.1:5173 、管理端 http://127.0.0.1:5177 、后端8080；原数据库 `cfd_demo_manual_20261026` 保留。演示管理员 `admin / 123456`，小程序开发验证码 `123456`。

Windows在仓库根目录停止、重启已有演示环境：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/stop-local.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-local.ps1 -Database cfd_demo_manual_20261026
```

脚本支持显式传入Python、Java及便携依赖目录。首次使用其他环境请先按部署手册安装依赖和构建各端。启动器仅使用 `cfd_demo*` 库，空库才执行初始化/迁移/种子；已有库保留数据。后端运行JAR独立复制到本机日志目录，避免Windows锁定Maven构建输出。停止仅处理记录且启动时间匹配的应用进程，保留MySQL、Redis与数据。

微信开发者工具导入 `front/dist/build/mp-weixin`。源码修改后重新执行 `npm run build:mp-weixin`，再点击开发者工具编译。该产物不提交Git，拉取源码后需构建。
