# 毕设需求与验证对应

来源为课题大纲的去联系方式摘要和四 Agent 方案。核心范围只有用户端、管理端、真实数据、基础配送/自提、团购、消费记录、销量及团购统计。独立商家、自提点运营端与复杂营销不作为已交付能力。

| 需求 | 实现入口 | 验收证据 |
| --- | --- | --- |
| 微信小程序及页面生命周期/组件/事件/缓存 | front/ uni-app Vue3，登录、地址、购物车、订单与拼团页面 | 微信构建；A13 真机另验 |
| 商品展示与管理 | /api/dishes，/admin/dish、/admin/category | A03、A06、A07 |
| 地址维护及用户隔离 | /user/addressBook | A02、A11 |
| 团购下单购买 | /user/groupon/open、join、detail、mine | A04、A05 |
| 服务端价格及库存 | 公共 CheckoutService 与事务数据库 | A06、A07，公开接口验证 |
| 订单跟踪与消费记录 | /api/orders、/api/orders/{id} | A08、A09、A14 |
| 送货与社区自提 | 后台接单、配送、完成、提货码核销 | A10、A11 |
| 销量、营业额及团购分析 | /admin/report/* | A12；固定独立样例对账 |
| 可运行程序与源码 | 三模块后端、用户端、管理端、独立初始化/迁移/种子、CI | A01 与部署手册 |
| 论文与答辩事实材料 | docs/thesis/ | 引用真实实现与验收记录；不包含教师联系方式 |

状态以最终 acceptance-report.md 为准。H2 控制器/公开服务测试、真实 MySQL 外部 HTTP、浏览器以及微信真机是不同证据层，不能相互替代。
