# 管理端品牌与界面重构验收（2026-10-27）

## 实现范围

用户要求重新设计后台，并替换仍显示的苍穹外卖图片与信息。本轮由本地 Gemini 使用 `frontend-design` 技能设计和编写页面，Codex 集成、校准文案并验收。

- 品牌统一为“社区鲜选 / 生鲜运营管理”，替换登录页餐饮大图、侧栏完整及折叠 Logo、网页标题、favicon、应用 manifest 和 404 页面。
- 采用生鲜绿、深绿侧栏和浅色业务页面；更新六模块的表格、筛选、状态、表单、分页和统计展示。原 Vue2 外壳和 Vue3 内嵌业务页架构保留。
- 登录页使用新生成的装饰生鲜图，压缩后约 240KB；演示苹果和青菜分别替换对应的示意图片。图片沿用演示资源路径，不改商品数据库记录。图片性质见 `front/static/images/png/DEMO-IMAGES.md`。
- 菜单使用 Lucide 的商品篮、分类、订单、团购和统计图标，保留开源许可；原工程 LICENSE 与 UPSTREAM 保留。
- 修正原 1366px 最小宽度和内外双滚动条；修复主题覆盖造成的“编辑”按钮白字问题。
- 清理餐厅、未证实的直采/即时配送承诺及实现教学文案；订单金额、注册用户、派送中等说明按已有实际口径展示。

## 业务保护

集成时保留各业务页原脚本；展示方面新增当前模块标题和菜单图标映射。对 18 个接口、状态、服务、路由和依赖清单文件作基线比较，未发现变动。导航守卫只调整浏览器标题文字，鉴权分支不变。后端、计价、库存、付款、核销及 token 同步没有修改。
