# 改动说明-m21

> 社区自提与团长核销链路改动说明

## 改动清单

### 1. 数据库脚本（`sky-server/src/main/resources/db/m21-pickup-verify-migration.sql`）

执行方式：
```bash
mysql -u root -p sky_take_out < sky-server/src/main/resources/db/m21-pickup-verify-migration.sql
```

| 表 | 字段 | 说明 |
| --- | --- | --- |
| `orders` | + `pickup_code` VARCHAR(16) | 8 位提货码，凭码取货 |
| `orders` | + `pickup_time_slot` VARCHAR(64) | 预约提货时间段 |
| `orders` | + `pickup_person_name` / `pickup_person_phone` | 提货人信息快照 |
| `orders` | + `verify_status` TINYINT NOT NULL DEFAULT 0 | 核销状态 |
| `orders` | + `verify_time` DATETIME | 核销时间 |
| `orders` | + `pickup_point_name` VARCHAR(64) | 自提网点名称快照 |
| `orders` | `address_book_id` 改为可空 | 自提订单无需配送地址 |
| `pickup_point` | + `latitude` / `longitude` / `image` | 自提点经纬度与门头图 |

### 2. 下单流程适配（`OrderServiceImpl#submitOrder`）
- 依据 `pickupPointId` 是否为 `null` 进行分支处理：自提模式无需地址校验，保存自提提货人信息并生成唯一提货码。

### 3. 核销流程
- 团长端/管理端通过提货码或者订单号核销，更新 `verify_status=1` 及 `verify_time`。
