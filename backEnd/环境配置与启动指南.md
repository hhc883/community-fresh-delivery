# 苍穹生鲜配送环境配置与启动指南

> 本文件记录本项目在当前环境下的全量配置与启动说明。

## 一、环境版本要求

| 软件 | 版本要求 | 用途 | 是否必需 |
| --- | --- | --- | --- |
| JDK | **21**（推荐 Dragonwell 21） | 编译 + 运行后端 | 必需 |
| Maven | 3.9+ | 依赖管理与打包 | 必需 |
| MySQL | 8.0+ / 8.4+ | 业务数据存储 | 必需 |
| Redis | 5.0+ | 缓存 / 状态存储 | 必需 |
| Nginx | 1.20+ | 管理端 PC 前端反代 | 可选（管理端通过 Nginx 运行） |
| 微信开发者工具 | 最新版 | 微信小程序联调 | 可选（仅小程序端需要） |

> **JDK 版本说明**：
> 本项目已升级 Lombok 1.18.34，支持 JDK 8~21，推荐使用 JDK 21 运行。

## 二、数据库准备

1. 启动 MySQL 服务；
2. 执行建表脚本：`sky_take_out.sql`；
3. 执行增量自提与核销迁移脚本：`sky-server/src/main/resources/db/m21-pickup-verify-migration.sql`；
4. 验证数据库：
```sql
USE sky_take_out;
SHOW TABLES;   -- 包含 address_book, orders, dish, groupon, pickup_point 等 14 张表
```

## 三、服务启动

### 1. 启动 Redis 与 MySQL
- 确保 Redis 监听 `6379` 端口；
- 确保 MySQL 监听 `3306` 端口。

### 2. 启动后端（8080 端口）
```bash
cd backEnd
mvn clean package -DskipTests
java -jar sky-server/target/sky-server-1.0-SNAPSHOT.jar
```
- 后端启动后访问 `http://localhost:8080/doc.html` 查看接口文档。

### 3. 启动前端（5173 端口）
```bash
cd front
npm install
npm run dev:h5
```
- 浏览器打开 `http://localhost:5173` 访问生鲜商城 H5 端。

### 4. 启动 PC 管理端
- 启动 Nginx（配置反代 `8080`），浏览器访问 `http://localhost/`；
- 默认管理员账号：`admin`，密码：`123456`。
